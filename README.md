## 📖 简介
这是论文《AeroFineFusion-Det: A Fine-Scale Bidirectional Multi-Scale Fusion Architecture for UAV Aerial Small-Object Detection》的官方实现。

### ✨ 主要特性
- ✅ 创新的细粒度双向多尺度融合架构
- ✅ 专为无人机航拍小目标检测设计
- ✅ 完整的训练和推理代码
- ✅ 预训练模型和详细复现指南
